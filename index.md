# Privacy Policy – Pir Visuals

**Effective Date:** October 31, 2026  
**Last Updated:** October 31, 2026

## 1. Introduction

Pir Visuals ("the Bot", "we", "our", or "us") is a WhatsApp-based bot designed to provide tools and utilities for design communities.

This Privacy Policy explains how Pir Visuals handles information when users interact with features that use the Pinterest API.

By using the Pinterest-related features of Pir Visuals, you acknowledge the practices described in this Privacy Policy.

## 2. Information We Access

When users use Pinterest search features, Pir Visuals may process the following information:

- Search keywords submitted through bot commands.
- Public Pinterest Pin information returned through the Pinterest API, such as Pin IDs, image URLs, titles, and descriptions when available.
- API authentication credentials required to access Pinterest services.
- Technical information necessary to operate and troubleshoot the integration.

Pir Visuals does not request users' Pinterest passwords.

## 3. How We Use Information

Information accessed through Pinterest is used only to:

- Process user-submitted image search queries.
- Retrieve publicly available Pinterest content through authorized API access.
- Display or share relevant search results in WhatsApp conversations.
- Prevent duplicate image URLs from being sent repeatedly.
- Maintain and troubleshoot the Pinterest integration.

## 4. Pinterest API Usage

Pir Visuals uses the Pinterest API to retrieve Pinterest content according to the permissions granted to its application.

Our use of Pinterest data is subject to Pinterest's applicable Developer Guidelines, API Terms, and policies.

We do not claim ownership of Pinterest content. All content remains subject to the rights of its respective owners.

## 5. Data Storage and Retention

The Bot may temporarily or persistently store limited technical information needed to operate its features, including:

- Pinterest API access credentials, stored in the bot's server environment.
- Search history or previously processed image URLs to prevent duplicate results.
- Technical logs used for troubleshooting.

Information is retained only for as long as necessary for operational purposes or as required by applicable law.

Users should not submit passwords, private credentials, or other sensitive personal information through bot commands.

## 6. Data Sharing

We do not sell personal information.

Information may be processed by third-party services necessary to operate the Bot, including:

- Pinterest, when Pinterest API requests are made.
- WhatsApp, when users interact with the Bot through WhatsApp.
- Hosting or infrastructure providers used to operate the Bot.

These services process information according to their own privacy policies and applicable terms.

## 7. Data Security

We take reasonable measures to protect API credentials and operational information against unauthorized access, disclosure, alteration, or destruction.

Access tokens should be stored securely and must not be shared publicly.

However, no internet-based system can guarantee absolute security.

## 8. Third-Party Services

Pir Visuals may interact with third-party platforms, including:

- Pinterest: https://policy.pinterest.com/en/privacy-policy
- WhatsApp: https://www.whatsapp.com/legal/privacy-policy

We are not responsible for the independent privacy practices of these third-party services.

## 9. User Rights and Data Deletion

Users may contact the Bot administrator to request information about personal data associated with their use of the Bot or request deletion where applicable.

Requests can be submitted using the contact information below.

## 10. Children's Privacy

Pir Visuals is not intentionally designed to collect personal information from children.

If you believe that a child has provided personal information through the Bot, please contact the administrator so that the matter can be reviewed.

We may update this Privacy Policy when our services, integrations, or legal requirements change.

The latest version will be published at the same Privacy Policy URL.
